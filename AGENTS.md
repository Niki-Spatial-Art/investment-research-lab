# Investment Research Lab Instructions

## Scope

This repository is for public, reusable investment research workflows.

Use it for:

- ETF and public equity research workflows
- market data source notes
- financial statement and filing analysis playbooks
- risk-control frameworks
- backtesting or monitoring resources
- public GitHub/resource indexes

Do not publish private account data, exact positions, trade logs, credentials, or personal financial records.

## Preferred Codex Routing

- Use finance/data skills when the task involves markets, ETFs, filings, valuation, risk, factors, or backtests.
- Use `Spreadsheets` when the task involves Excel, CSV, tables, charts, or report workbooks.
- Use `edgar-sec-filings`, `financial-statement`, `valuation-model`, `risk-analysis`, `yfinance`, `akshare`, or related market-data skills when relevant.
- Use `report-generate` for polished research notes.

## Output Style

- Start with the conclusion.
- Separate facts, assumptions, and opinions.
- Include risk caveats.
- Avoid deterministic investment advice.
- Prefer public sources and reproducible workflows.

## Safety

- Never imply guaranteed returns.
- Do not store private portfolio details here.
- If data is current or market-sensitive, verify it with live sources before writing.
