# Investment Research Lab

投研与交易方向的公开收藏仓库。

这个仓库用于整理 ETF 主线、市场监控、交易纪律、财报速读、策略复盘、数据源和量化工具。它更像一个可持续维护的投研工具箱，而不是一次性资料夹。

## What Goes Here

- ETF / 行业主线监控
- 盘前计划和盘后复盘
- 财报速读和风险扫描
- 量化工具、数据源、研究框架
- 值得收藏或 fork 的投研 GitHub 项目

## Structure

- `repos.md`: 投研相关 GitHub 仓库索引
- `playbooks/`: 可重复执行的投研流程
- `templates/`: 研究、复盘、仓库登记模板
- `archive/`: 历史记录和阶段性判断

## Risk Note

This repository is for research workflow organization only. It does not provide financial advice or guaranteed investment conclusions.
